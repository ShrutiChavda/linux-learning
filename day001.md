# Day 001 - Linux Basic Commands...

1. pwd - Displays the current working directory.
2. ls - Lists files and directories.
3. ls -la - Lists all files, including hidden files, with details.
4. cd - Changes the current working directory.
5. cd ~ - Moves to the user's home directory.
6. mkdir - Creates a new directory.
7. touch - Creates an empty file or updates its timestamp.
8. echo - Displays text in the terminal.
9. sudo apt update - Refreshes package information.
10. sudo apt upgrade -y - Installs available package upgrades.
