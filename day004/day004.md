Key Takeaways:

Guest Additions improve integration between a Linux guest and VirtualBox.

uname -r checks the Linux kernel version.

lsb_release -a checks the Ubuntu version.

apt update refreshes package information; apt upgrade installs updates.

df -h checks filesystem capacity and available space.

du -sh summarizes directory or file storage usage.

Windows sleep can interrupt a running VM.

Normal VM shutdown is preferable before leaving the laptop unused for an extended period.

Virtual disk capacity and actual Windows disk usage are not necessarily the same.
